Two Soln. Paths 1. The top-level Podman container (running the CircleCI execution environment) is spawned by Nomad as an unprivileged user. When it attempts to launch the inner container, it needs to slice up its given UIDs via /etc/subuid and /etc/subgid. If the top-level container was not allocated a subordinate range by the underlying Nomad host, it throws a sys-cap error or crashes instantly.

a. Configure the Nomad Job Spec for Namespaces
b. Configure Top Container Storage for Nesting

  1. Tests can Spike cpu usage to 250% on initianalization. The unprivileged nested Podman layers see the entire underlying Nomad host hardware (e.g., a 32-core or 64-core bare-metal machine). If the runner job tries to immediately spawn 64 parallel threads, it will briefly hit 250%+ CPU utilization right at initialization a. We can try enforcing a hard resource limit to prevent resource spiking and mem exhaustion
