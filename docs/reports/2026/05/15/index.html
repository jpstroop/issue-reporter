Jane Sandberg at 2026-05-15 00:37:22 :

I believe this issue is happening because when a holding has no item information, our code looks in the solr document's holdings_all_display method to get item information, with the theory that this may be a constituent record whose host record contains some relevant item information. This logic arose as part of #3273

However, holdings_all_display contains information from the current record as well as any host records -- so if the record is not a bound-with (or even if it is), holdings_all_display can just as easily return another holding from the same record, leading to this situation. It seems that we should be more selective than just taking the first entry from holdings_all_display and hoping for the best.
