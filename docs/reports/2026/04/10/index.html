#7019 Inventory files failing to parse

Creator:

Status:

Comments:
Alicia Cozine at 2026-04-10 14:50:39 :

The pattern for ansible-inventory usage is -i <inventory-file-or-dir> <group_name> --graph. And since we set the inventory in our ansible.cfg file, you don't need to pass it.

For example, the command for "show me all the machines that belong to the staging group" would be:

ansible-inventory -i inventory staging --graph

If you pass the file name (-i inventory/by_environment/staging) instead, Ansible reads that as the entire inventory. And then it can't find any of the groups mentioned as child groups because it isn't even trying to parse the other files in the inventory directory.
